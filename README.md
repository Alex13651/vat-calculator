# Калькулятор НДС по странам мира

Веб-приложение на Python (Flask) для расчёта НДС, сравнения налоговых ставок и визуализации данных.

## Возможности
- Живой поиск по 171 стране (с учётом синонимов и опечаток).
- Расчёт НДС «сверху» (начисление) и «из суммы» (выделение).
- Интерактивная карта мира с цветовой индикацией ставок.
- Графики сравнения стран, распределения ставок и топ-5.
- Справка по областям применения (льготы, пониженные ставки, экспорт).
- Учёт будущих изменений (например, ставка 22% в России с 2026 года).

## Технологии
- Python 3
- Flask
- Chart.js (для графиков)
- Plotly.js (для карты)

## Запуск локально
1. Клонируйте репозиторий:
   `git clone https://github.com/Alex13651/vat-calculator.git`
2. Перейдите в папку:
   `cd vat-calculator`
3. Создайте виртуальное окружение:
   `python3 -m venv .venv`
4. Активируйте его:
   `source .venv/bin/activate` (macOS/Linux)
5. Установите зависимости:
   `pip install -r requirements.txt`
6. Запустите сервер:
   `python app.py`
7. Откройте в браузере `http://127.0.0.1:5000`

## Важно
Данные о ставках носят справочный характер и могут устаревать. Перед реальными расчётами сверяйтесь с официальными источниками.
